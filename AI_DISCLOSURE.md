It is a requirement by the Archipelago community to disclose LLM AI usage. This file is used to disclose usage.

I use the term LLM to describe a specific type of AI model that was used during development. There are plenty of other types of AI that aren't as notorious or controversial as LLMs.

- Most of this project was not developed with the help of LLMs with the exception of these cases:
  - The Mod: A few parts of the code (like APClient) were LLM assisted in terms of finding bugs and suggesting fixes.
  - Helpers:
    - All Helpers except for FVerParser: ChatGPT was involved at designing a basic example for me to base the code from to reduce time.
    - FVerParser: Coded by me.
  - Tests: The unit test system was designed and written by me and most of the research to design it was not involving AI (sifting through the docs, searching nuget, etc). Some of the tests, themselves, however, were AI written/revised to improve the quality of the tests. The tests were strictly audited and tested. I do not use AI for coding these days, but there are still AI touched code there. Binaries of the game do not contain this code.

- Some of the subprojects that this project depends on HAS involved LLMs to some degree including:
  - native-websocket-sharp: That project was used as an LLM experiment to try out the capabilities of LLM coding. Earlier iterations of this project were AI written before the final design was hand written (because the first iteration was a sloppy mess). Most of that project is considered "AI Assisted". That has it's own [AI_DISCLOSURE](https://github.com/JKLeckr/native-websocket-sharp/blob/main/AI_DISCLOSURE.md) file.

- Art and Creative assets are NOT and NEVER will be generated by LLMs. I am strict with this.

While there are parts of the project that are "AI touched" (I experimented with it a couple of times to find a specific issues and to improve the tests), I primarily work on this project by hand. There may be contributions in the future that may have involved LLMs in the future (though, I dislike slop very much, I am not anti-AI). I will note those cases here if there are LLM involved contributions.

I take pride in my work, and I am very picky about code quality, so I make sure the code I push out is something I can be happy with.
